# AI Study Planner Agent

A simple working Flask web app based on the supplied college project report.

## Features
- Student dashboard
- Subject and exam information
- AI-style priority calculation
- Study-plan generation
- Task completion tracking
- Adaptive re-planning for missed tasks
- Simple study assistant API
- Responsive UI

## Run
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

This starter implementation keeps the first version simple while demonstrating the Analysis, Planning, Progress, and Re-planning agent behavior described in the report.
